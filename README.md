# 🏭 JSW Vijayanagar Industrial Analytics Dashboard

Production | Energy | Sustainability | Raw Materials | Digitalisation

## 📌 Project Overview

This project focuses on industrial performance and sustainability analytics for JSW Vijayanagar Integrated Steel Plant. Using Microsoft Power BI, the project aims to analyse steel production, capacity utilisation, energy consumption, water intensity, air emissions, waste management, raw material consumption, and digitalisation metrics.

The objective is to transform structured data into interactive dashboards that help users understand operational performance, identify trends, and explore opportunities for improvement.

##🎯 Project Objectives

- Analyse steel production and capacity utilisation.
- Monitor energy consumption and energy intensity.
- Evaluate water consumption per tonne of crude steel.
- Analyse PM, SO₂, and NOx emission metrics.
- Examine waste generation, utilisation, and category-wise distribution.
- Identify major raw materials by consumption and intensity.
- Explore digitalisation initiatives and reported operational metrics.
- Present meaningful insights through interactive Power BI dashboards.

## 🛠️ Tools & Technologies

- Microsoft Power BI — Interactive dashboards and visualisation
- Power Query — Data cleaning and transformation
- DAX — Measures and KPI calculations
- Microsoft Excel — Source data and initial exploration

## 📂 Dataset Overview

The master Excel workbook contains the following subject areas:

Dataset| Analysis
Production| Steel production and capacity utilisation

Air Emissions| PM, SO₂, and NOx metrics

Digitalisation| Digital initiatives and reported metrics

Note: The dataset's source, provenance, reporting periods, and permission to share will be documented and verified before publication.

### 🔄 Project Workflow

1. Inspect and understand the source data.
2. Clean and transform the data using Power Query.
3. Validate data types, missing values, duplicates, and record provenance.
4. Build a financial-year dimension and establish data relationships.
5. Create appropriate DAX measures and KPIs.
6. Develop interactive Power BI dashboards.
7. Validate calculations and document key findings.
8. Publish project documentation and permitted dashboard screenshots on GitHub.

- Capacity utilisation (%)

- Specific water consumption (m³/tcs)

### 💡 Business Value

This project demonstrates how industrial data can be organised and analysed to:

- Monitor operational performance.
- Compare resource consumption and efficiency.
- Understand environmental performance indicators.
- Identify changes in waste utilisation.
- Examine raw material consumption patterns.
- Communicate findings through interactive visualisations.

The dashboard supports analytical exploration; it does not independently establish causation or prove that a digital initiative improved plant performance.
